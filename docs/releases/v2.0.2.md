# v2.0.2: M1 Foundation

The test foundation the rest of the roadmap stands on, and the first matching fixes, each shipped with its tests.

- **Tests:** an xUnit project with fixtures and a job-description corpus (TEST-01), unit tests per helper (TEST-02),
  invariant tests that hold the app to "nothing invented" plus ordering and limits (TEST-03), document tests for DOCX
  structure and PDF pages and text (TEST-04), and API integration tests (TEST-05).
- **Matching:** fuzzy-match false positives fixed (MATCH-01), word-boundary ATS keyword density (MATCH-02), one shared
  date parser and the correct "most recent role" (MATCH-03).
- **Engineering:** duplicated logic consolidated and the selection made immutable (ENG-02); `ILogger` and
  ProblemDetails, so no exception text reaches a client (ENG-03).
- **CI:** GitHub Actions builds and tests every push and pull request (OPS-01).
