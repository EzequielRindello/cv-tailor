# v2.0.3: M2 Redesign

A new, editorial interface, tested end to end in a real browser.

- **Design system** with tokens, self-hosted fonts and dark mode (UX-01); a new app shell and hero (UX-02).
- **A guided three-step composer** (UX-03) and a **results workspace** that shows the CV instead of downloading it
  straight away (UX-04).
- Score visualizations (UX-05), generation progress and skeletons (UX-06), empty, error and toast states (UX-07).
- **Accessibility** to WCAG AA, including keyboard reordering (UX-08), and a responsive pass down to phone widths
  (UX-09).
- A gallery of sample job descriptions to try the app in one click (APP-03).
- **Playwright end-to-end tests** written against the new UI (TEST-07).
