# v2.0.6.1: M5.1 Smarter input

Less typing to get started.

- **Required vs nice-to-have** follows the sections of the job post (MATCH-06).
- **Start your profile from your resume:** a PDF or Word file is read into a draft you check before saving
  (PROF-05). The file is read in memory and never stored.
- **Take the job post from its link:** paste a Greenhouse or Lever link and the post is read from the board's public
  API (APP-04).

Also in this release, the UX polish after M5: profile cards in step 2, a favicon, confirmation before deleting data,
a cleaner history panel, a Profile link in the header, save buttons that only enable when something changed, and
checkboxes in the app's colors. And a fix: text no longer depends on the server's culture (Linux runs with the invariant
culture, which printed "12 %" where Windows printed "12%").
