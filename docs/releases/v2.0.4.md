# v2.0.4: M3 Your data

Bring your own profile, and see why the CV came out the way it did.

- **Your profile:** an in-browser profile editor (PROF-01), JSON import and export with validation (PROF-02),
  generate from it (PROF-03), and a health check that points at what is missing or weak (PROF-04). It stays in your
  browser.
- **Explainability:** "why this was chosen" for every role, bullet, skill and project (MATCH-04), and the job post
  with every skill highlighted and linked to where it appears in the CV (MATCH-05).
- **Workflow:** an application tracker with status, company and notes (APP-01), re-open a past generation (APP-02).
- **A real job-post corpus**, dated and linked to the originals, collected from public job-board APIs (APP-05).

Between this release and the next, a system hardening pass (no version change): templates cached and HTML rendered
once, request and job-description limits, a cap on concurrent PDF renders, security headers and HSTS, a non-root
container, and the domain moved to one folder per feature.
