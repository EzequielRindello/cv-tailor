# v2.0.6.2: M5.2 Pre-deploy polish

Everything that had to be right before the app went public.

- **Resume import:** a tooltip explains the limits, and a wrong type, a file that is too big or a scanned PDF is
  refused before it is read (PROF-07).
- **The summary reads the role correctly:** one stray mention no longer sets it (MATCH-10), and a role the post names
  repeatedly counts (MATCH-11).
- **Editing:** add back what the selection or the page fit left out (EDIT-07); the match, ATS, keyword and gap scores
  follow the edited CV (EDIT-08), and the match card also shows the whole profile's match when the CV prints only part
  of it; a page warning when an edit makes the CV or the letter run past its pages (EDIT-07, EDIT-10).
- **Cover letter:** it names the company, has a real salutation, and its text can be edited (EDIT-09); the company
  edited in the tracker updates the open letter (APP-09).
- **API:** the job post import is an endpoint with its own per-IP rate limit (APP-07), and a 429 carries an error body
  and a `Retry-After` (APP-08).
- A progress bar while a CV is rendered, for the generation and for edited downloads (UX-11).
- Reviewed in the browser in light, dark and at phone width before the deploy; line coverage 98%.
