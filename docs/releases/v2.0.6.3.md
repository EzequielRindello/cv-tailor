# v2.0.6.3: M5.3 Deploy

The first public deploy. **Live demo: https://cv-tailor-9z6e.onrender.com**

- **Deployed on Render** as one Docker web service from `render.yaml`, with the health check on `/api/cv/health`
  (OPS-06). The free plan sleeps when idle, so the first visit after a quiet spell takes a moment to wake it up.
- **The repository is ready for visitors** (OPS-07): renamed to `cv-tailor`, MIT license, security and contributing
  guides, issue and pull request templates, line endings settled with `.gitattributes`, a coverage badge that CI keeps
  honest, and these release notes for every milestone.
- **The app is called CV Tailor** in its header, hero and page titles, the same name as the repository. The
  wordmark in the header starts over: on the home page it reloads it with an empty composer (U9).
- **The rate limit counts each visitor** behind Render's proxies (Cloudflare's edge, then Render's own), so the
  per-IP API and import limits apply on the live instance, and a made-up `X-Forwarded-For` still buys nothing (F32).
