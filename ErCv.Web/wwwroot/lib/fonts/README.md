# Fonts

Self-hosted variable fonts (latin subset), from the npm packages `@fontsource-variable/inter`, `@fontsource-variable/fraunces` and `@fontsource-variable/jetbrains-mono`, version 5.3.0, via cdn.jsdelivr.net.
